Who owns each field

FieldOwnerOthers mayNever
Post text and photos Jamie WT Builder reprints a post in the Journal and mirrors Jamie's edits back (hop 4). The Library Agent edits a post's words.
Blog categories and their descriptions Librarian Jamie edits freely in micro.blog; WT Builder sets the Weekly Thing category on reprinted posts. The Library Agent overwrites a category a person chose. It files unfiled posts and proposes changes in its report. Descriptions are micro.blog's Intro field, set by hand.
Alt text on blog photos Librarian Jamie writes alt when posting. The Library Agent changes alt that is already there, or turns an <img> into markdown.
Featured Librarian Jamie decides on the first list before anything is written. A Featured write without Jamie having seen the list.
Issue content WT Builder The Librarian copies it and adapts the copy for the corpus; weekly.thingelstad.com renders it and is the source of authority once sent. A surface edits an issue.
Saved link and its note Jamie WT Builder mirrors Jamie's commentary back (hop 2); Linking Things and the Librarian read. A note rewritten by a system without the _agent tag.
Read/unread on a bookmark Jamie Nothing. WT Builder neither selects on it nor writes it. A system flips it.
Topic graph Librarian weekly.thingelstad.com renders it (hop 17). A topic edited on the site.
Episode content and audio WT Builder another.thingelstad.com publishes it; the Librarian imports the transcript (hop 12). A hand edit on the site once the send runs (today, every episode was a hand commit; see hop 21).

SystemThe fact that shows what it holdsNotes
Pinboard

micro.blog

Tinylytics
source · tinylytics.app		 Site and page view counts over its API (key needed). Reader counts only; never content.
WT Builder

The sync probe records it as WT Builder's fact and shows the item's journey from that moment. get_status (MCP) shows each issue's send legs; list_events shows what was sent when. Authors and publishes each issue, and makes Another Thing since 2026-10-11 (that send has not run yet).
